## 📚 算法简介

**Kadane 算法**是一个经典的动态规划算法，用于在 O(n) 时间复杂度内找到一个数组中具有最大和的连续子数组。

### 核心思想

算法的核心思想非常简单而优雅：
- **如果当前累积和变成负数，就放弃这段子数组，从下一个元素重新开始**
- 为什么？因为负数只会让后续的和变小，不如重新开始
- 在遍历过程中记录最大和，最终返回这个最大值

### 算法步骤

1. 初始化两个变量：
   - `currentSum = 0`：当前子数组的和
   - `maxSum = nums[0]`：到目前为止找到的最大和

2. 遍历数组的每个元素：
   - 将当前元素加到 `currentSum` 上
   - 如果 `currentSum` 小于当前元素本身，说明之前的累积是负担，重新从当前元素开始
   - 更新 `maxSum` 为 `currentSum` 和 `maxSum` 中的较大值

3. 返回 `maxSum`

### 时间和空间复杂度

- **时间复杂度**：O(n) - 只需遍历一次数组
- **空间复杂度**：O(1) - 只需要常数个变量

## 💡 关键洞察

### 为什么要重新开始？

当累积和变成负数时，继续累加只会拖累后面的元素。例如：

```
[-2, 1] vs [1]
累积和 -1  vs 累积和 1
```

显然从 1 重新开始更好！

### 为什么只需要一次遍历？

因为算法利用了**贪心策略**：
- 在每个位置，我们只关心"以当前元素结尾的最大子数组和"
- 这个值只依赖于前一个位置的结果
- 不需要回头重新计算

## 🤔 常见问题

**Q: 如果数组全是负数怎么办？**  
A: 算法会返回最大的那个负数（即最小损失）。

**Q: 能找到多个具有相同最大和的子数组吗？**  
A: 标准算法只返回最大和的值，不返回具体子数组。如果需要找到所有解，需要修改算法记录所有达到最大和的子数组。

**Q: 这个算法能用于其他问题吗？**  
A: 是的！Kadane 算法的思想可以应用到许多类似的动态规划问题中，比如最大乘积子数组、买卖股票等。
